# Priyanshi Gajiwala — Portfolio

A premium multi-page portfolio website built with React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and React Router.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — Build tool
- **Tailwind CSS v4** — Styling
- **React Router DOM** — Multi-page routing
- **Framer Motion** — Animations
- **React Icons** — Icon library
- **shadcn/ui** — UI components

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Push to GitHub and import the repository in [Vercel](https://vercel.com). The included `vercel.json` handles SPA routing.

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/about` | About |
| `/projects` | Projects |
| `/projects/:slug` | Project Details |
| `/experience` | Experience |
| `/research` | Research |
| `/achievements` | Achievements |
| `/resume` | Resume |
| `/blog` | Blog |
| `/contact` | Contact |

## Features

- Animated page transitions
- GitHub API integration
- Command palette (Ctrl/Cmd + K)
- Scroll progress indicator
- SEO metadata per page
